# Nsisong Labs

Nsisong Labs is a software studio building practical systems, developer tools, and product infrastructure for teams that need reliable engineering without unnecessary ceremony.

We work across full-stack product development, automation, backend systems, cloud infrastructure, security-minded code review, and domain-specific tooling. This GitHub organization is where we publish reusable work from that practice.

## What We Build

- Small developer tools that solve clear operational problems.
- Backend and infrastructure utilities for product teams.
- Libraries and datasets useful to builders working in Nigeria and across Africa.
- Reference implementations, templates, and examples from our engineering practice.
- Product experiments that are useful enough to stand on their own.

## Tool Lab

We maintain a growing catalog of focused public tools. Each tool is intended to be small, documented, tested, and useful without requiring a whole platform around it.

Current public tools include:

- [`secret-redactor`](https://github.com/nsisongltd/secret-redactor): local redaction for secrets in logs, files, and terminal output.
- [`backup-freshness-check`](https://github.com/nsisongltd/backup-freshness-check): local backup age, size, and naming checks for cron, CI, and maintenance workflows.

More tools will be added gradually across TypeScript, Rust, Go, and Python.

## Engineering Standards

Public repositories should be straightforward to inspect and run:

- Clear README and examples.
- Tests for the core behavior.
- CI for formatting, linting, and tests where appropriate.
- Architecture notes for decisions worth preserving.
- Honest limitations rather than inflated claims.
- Practical defaults that make the first useful path quick.
