# Nsisong Labs

Nsisong Labs is a development agency building software products, internal tools, automations, and platform infrastructure for growing teams.

We work across full-stack development, backend systems, cloud infrastructure, automation, product engineering, and security-minded code review.

## Work

- Product development
- API and backend engineering
- Automation and workflow systems
- Cloud and deployment support
- Security code audits
- Developer tooling

## Public Tools

We also publish small reusable tools from our engineering practice:

- [`secret-redactor`](https://github.com/nsisongltd/secret-redactor): local redaction for secrets in logs, files, and terminal output.
- [`backup-freshness-check`](https://github.com/nsisongltd/backup-freshness-check): local backup age, size, and naming checks for cron, CI, and maintenance workflows.
- [`semver-guard`](https://github.com/nsisongltd/semver-guard): package surface checks for accidental breaking changes.
